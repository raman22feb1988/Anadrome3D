# Anadrome3D

Anadrome had been an omnidirectional Scrabble variant with 40 new bonus tiles, a board editor fed by a tile inventory mechanic and definitions provided per turn.

The original website https://anadro.me had been shut down on 7<sup>th</sup> August 2026, but it had been interesting for me to recreate it by modding the latest version 4.0 of Scrabble3D.

With this mod, it will be possible for anyone to play with the latest official version of the English dictionary, to play with the upper limit of 2<sup>1024</sup> points on scores being removed, to play up to 4 players, to play 3D games, to play without any of the tile inventory restrictions and to optionally disable the playing of words in the backward direction.

More information about it is available at https://www.scrabble3d.info/t2594f366-fun-bonus-tiles-as-in-Anadrome.html.
